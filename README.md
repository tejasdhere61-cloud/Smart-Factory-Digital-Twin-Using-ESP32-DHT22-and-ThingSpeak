# Smart-Factory-Digital-Twin-Using-ESP32-DHT22-and-ThingSpeak
This project is a Smart Factory Digital Twin using ESP32, Wokwi, and ThingSpeak. It monitors temperature, humidity, vibration, and machine status. Wokwi simulates the sensors and ESP32, while ThingSpeak displays the data as online graphs. The project demonstrates IoT, cloud monitoring, sensor simulation, and Digital Twin technology.
